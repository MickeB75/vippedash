App icons for manifest.json. Right-click a canvas and save it as the file named in its title, or let headless Chrome save one (?only= shows just that icon at 0,0 on a transparent page):

chrome --headless --hide-scrollbars --default-background-color=00000000 --window-size=512,512 --screenshot=icons/icon-512.png "http://localhost:8765/tools/icons.html?only=icon-512.png"
