VippeDash level lint

The page half of python tools/lint.py: for each level it checks the theme against the level's areas, then builds the level and draws it with the real renderer (js/render.js, 1280x720, offscreen) at x = 0, 10, 20, ... (step=) to the finish, at every checkpoint and with a few different times, collecting exceptions, unknown style names (the VD.lintMiss hooks in js/art.js and js/render.js) and console errors. The result is a JSON report in #report. Parameters: level=a,b (default all), step=10 (x step in blocks), scale=0.5 (pixel buffer scale), drop=chess.ground.board,... (delete theme.<map>.<key> of a level before checking, to prove that a check works without editing level.js).
