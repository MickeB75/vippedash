VippeDash level map

Draws a schematic top-down/side map of a level's layout (not the game's art), so a level's rhythm and hitboxes can be checked at a glance. Query params: level=<id> (default: the first level), from=<x> / to=<x> (block range to draw, default the whole level), cols=<n> (blocks per row, default 100), scale=<n> (pixels per block, default 12), bot (run the search bot from every checkpoint and draw its path, red where a segment fails) and windows (implies bot; also colour each press by its timing slack: green >= 90 ms, yellow 50-89, red < 50).
